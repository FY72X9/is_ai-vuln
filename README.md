# is_ai-vuln

> **AI-Driven Performance Analysis using Fuzzy DEMATEL: A Simulation-Based Experimental Framework**  
> *Targeting Q1 Journal Publication in Information Systems & Computer Science (2026)*

---

## 📌 Overview

This repository houses the research framework, experimental code, and data pipelines for evaluating modern tabular and graph AI architectures in intrusion detection and cybersecurity vulnerability classification, integrated with **Fuzzy DEMATEL** causal network modeling.

Key components:
- **Architectures evaluated**: TabPFN v3, TabICL v2, GraphIDS, SAINT, Mambular (Mamba SSM), FT-Transformer
- **Datasets**: NSL-KDD, CICIDS2017, UNSW-NB15
- **Methodology**: Simulation-based experimental framework + Fuzzy DEMATEL causal analysis
- **Reproducibility**: End-to-end Python pipelines with 5-fold cross-validation and statistical significance testing
